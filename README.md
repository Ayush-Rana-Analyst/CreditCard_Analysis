 Credit Card Financial Report (SQL + Power BI)

 📌 Overview
This project analyzes credit card financial data using **SQL** and **Power BI**.  
It demonstrates data cleaning, querying, and dashboard creation to uncover customer spending behavior, transaction trends, and financial performance.

 📂 Dataset Information
The repository includes four CSV files:
- **cc_add.csv** → Credit card account details  
- **credit_card(1).csv** → Transaction records and card usage data  
- **cust_add(1).csv** → Customer address and demographic details  
- **customer(2).csv** → Customer master data  

 🎯 Project Scope
- SQL queries for:
  - Data cleaning and transformation  
  - Aggregations (SUM, AVG, COUNT)  
  - Customer segmentation and spending trends  
  - Risk analysis  

- Power BI dashboards for:
  - Customer spending behavior  
  - Transaction trends over time  
  - Segmentation and financial performance  

 🛠️ Tools Used
- SQL (for queries and data preparation)  
- Power BI (for dashboards and visualization)  

 📊 Key Insights
- Spending trends across different customer segments  
- Top categories of credit card usage  
- Monthly/quarterly transaction patterns  
- Indicators of financial risk  

 🚀 How to Run
1. Import all CSV files into your SQL database.  
2. Run queries from the `queries.sql` file (to be added).  
3. Connect SQL output to Power BI.  
4. Open the `.pbix` file to explore dashboards.  

📈 Purpose
This project is part of my **data analytics portfolio**, showcasing SQL query solving and Power BI reporting for financial datasets.
